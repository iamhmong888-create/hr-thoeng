# ระบบงานบุคลากร (สกร.ระดับอำเภอเทิง)

เว็บไซต์สำหรับครูดูและแก้ไขประวัติส่วนตัว บันทึกการพัฒนาตนเอง (ศึกษาดูงาน อบรม สัมมนา) พร้อมรูปหลักฐาน 2 รูป และหน้าผู้บริหาร (ผอ.) ที่ดูข้อมูลครูทุกคนได้

- **หน้าเว็บ** วางบน **GitHub Pages** (ฟรี)
- **ฐานข้อมูลและรูปภาพ** เก็บใน **Firebase Firestore** และใช้ **Firebase Authentication** สำหรับเข้าสู่ระบบ (แผน Spark ฟรี ไม่ต้องผูกบัตรเครดิต)

> ⚠️ **ห้ามนำไฟล์ข้อมูลบุคลากร (`staff_import.json`, Excel) ขึ้น GitHub** เพราะมีเลขบัตรประชาชนและเบอร์โทร ไฟล์นี้ใช้นำเข้าผ่านหน้าเว็บครั้งเดียวเท่านั้น (ไฟล์ `.gitignore` กันไว้ให้แล้ว)

---

## โครงสร้างไฟล์

```
index.html              หน้าเว็บ (หน้าเดียว ใช้ได้ทั้งครูและ ผอ.)
config.js               ตั้งค่า Firebase และชื่อหน่วยงาน
firestore.rules         กฎความปลอดภัยของฐานข้อมูล (วางใน Firebase Console)
assets/app.js           โปรแกรมหน้าเว็บ
assets/firebase-api.js  ส่วนเชื่อมต่อ Firebase
assets/style.css        รูปแบบหน้าเว็บ
.nojekyll               ให้ GitHub Pages เสิร์ฟไฟล์ตามจริง
```

## การใช้งาน

| ผู้ใช้ | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| ครู | ชื่อจริง (ไม่มีคำนำหน้า ไม่มีนามสกุล) เช่น `ศุภลักษณ์` | เบอร์โทรศัพท์ เช่น `0818848953` (เปลี่ยนได้ 1 ครั้ง) |
| ผู้ดูแลระบบ / ผอ. | `admin` | ตั้งเองตอนติดตั้ง |

- **ครู**: เมนู ประวัติส่วนตัว / การพัฒนาตนเอง / โล่/รางวัล / เป็นวิทยากร / เปลี่ยนรหัสผ่าน
- **ผอ.**: เมนู ภาพรวม / ข้อมูลบุคลากร / รายการพัฒนาตนเอง / โล่/รางวัล / เป็นวิทยากร / ตั้งค่าปีงบ-โครงการ
- **โล่/รางวัล และ เป็นวิทยากร**: ครูเพิ่ม/แก้ไข/ลบรายการของตนเองพร้อมรูปหลักฐาน 2 รูป ผู้บริหารดู ตรวจ และดาวน์โหลด PDF ได้เหมือนรายการพัฒนาตนเอง (มีตัวเลขรอตรวจบนเมนูแยกกัน)
- **ลืมรหัสผ่าน**: ครูกด “ลืมรหัสผ่าน?” ที่หน้าเข้าสู่ระบบ หรือ ผอ. กด “ส่งลิงก์รีเซ็ตรหัสผ่าน” ในข้อมูลครู ระบบจะส่งลิงก์ตั้งรหัสใหม่ไปที่อีเมลของครู
- **ครูที่ไม่มีอีเมล/อีเมลผิด**: ผอ. แก้อีเมลในข้อมูลครู แล้วกด **“สร้างบัญชีใหม่”** รหัสผ่านจะกลับเป็นเบอร์โทร
- **เพิ่มบัญชีผู้ดูแลระบบ (ผอ., หัวหน้างานบุคลากร)**: เมนู “ตั้งค่าปีงบ/โครงการ” > หัวข้อ “บัญชีผู้ดูแลระบบ” > “+ เพิ่มบัญชีผู้ดูแลระบบ” กำหนดชื่อผู้ใช้ อีเมล และรหัสผ่านเอง
- **ช่องรหัสผ่านมีปุ่มรูปตา** กดเพื่อแสดง/ซ่อนรหัสผ่านที่พิมพ์
- **ตั้งให้ครูเป็นผู้บริหาร**: แก้ข้อมูลครูคนนั้น ช่อง “สิทธิ์การใช้งาน” = ผู้บริหาร จะเห็นข้อมูลทุกคนและยังบันทึกการพัฒนาของตนเองได้
- **เพิ่มบุคลากรใหม่**: เมนูข้อมูลบุคลากร > “+ เพิ่มบุคลากร” ระบบสร้างบัญชีให้อัตโนมัติ (ต้องมีเบอร์โทร)
- **ตรวจรายการพัฒนาตนเอง**: ผู้บริหารดูรายการของทุกคนได้ แต่แก้ไข/ลบไม่ได้ กด “ตรวจรายการนี้” เพื่อบันทึก “ตรวจแล้ว” หรือ “ส่งกลับให้แก้ไข” พร้อมความเห็น ครูเห็นสถานะและความเห็นในหน้าของตน เมื่อครูแก้ไขรายการ สถานะจะกลับเป็น “รอตรวจ”
- **ดาวน์โหลด PDF**: ปุ่มในหน้าประวัติส่วนตัว หน้าการพัฒนาตนเอง (มีช่องลงชื่อผู้รายงานและผู้อำนวยการ) หน้าข้อมูลบุคลากร และหน้ารายการพัฒนาตนเองของผู้บริหาร กดแล้วระบบสร้างไฟล์ PDF ขนาด A4 และดาวน์โหลดลงเครื่องทันที (ถ้าเปิดเว็บจากในแอป LINE แล้วไม่ดาวน์โหลด ให้เปิดใน Safari หรือ Chrome)
- **เพิ่มปีงบประมาณ/โครงการ**: เมนู “ตั้งค่าปีงบ/โครงการ” (ติดตั้งครั้งแรกมีปี 2570 ให้แล้ว)

ถ้า `config.js` ยังเป็น `FIREBASE: null` เว็บจะเปิดใน **โหมดทดลอง** ด้วยข้อมูลตัวอย่าง (ครู: `สมชาย` / `0811111111`, ผอ.: `admin` / `admin1234`)

## ขั้นตอนติดตั้ง (ประมาณ 20 นาที)

### 1) สร้างโปรเจกต์ Firebase
1. เข้า <https://console.firebase.google.com> > **Create a project** ตั้งชื่อ เช่น `hr-thoeng` (ปิด Google Analytics ได้)
2. ใช้แผน **Spark (ฟรี)** ไม่ต้องอัปเกรด

### 2) เปิดระบบเข้าสู่ระบบ (Authentication)
1. เมนู **Build > Authentication > Get started**
2. แท็บ **Sign-in method** > เลือก **Email/Password** > เปิด **Enable** (ช่องแรก) > Save
3. แท็บ **Settings > Authorized domains** > **Add domain** ใส่ `<ชื่อผู้ใช้ GitHub>.github.io`
4. (แนะนำ) แท็บ **Templates** > Password reset > เปลี่ยนภาษาเป็น **Thai**

### 3) สร้างฐานข้อมูล Firestore
1. เมนู **Build > Firestore Database > Create database**
2. Location: **asia-southeast1 (Singapore)** (ใกล้ไทย อ่านข้อมูลเร็ว) — เลือกแล้วเปลี่ยนภายหลังไม่ได้
3. เลือก **Start in production mode** > Create
4. แท็บ **Rules** > ลบของเดิม วางเนื้อหาทั้งหมดจากไฟล์ `firestore.rules` > **Publish**

### 4) เอาค่าการเชื่อมต่อมาใส่ config.js
1. ⚙️ **Project settings** > เลื่อนลงที่ **Your apps** > กดไอคอน **Web `</>`** > ตั้งชื่อแอป > Register app (ไม่ต้องติ๊ก Hosting)
2. คัดลอกค่าใน `firebaseConfig` มาวางใน `config.js` แทน `null`:
   ```js
   FIREBASE: {
     apiKey: "AIza...",
     authDomain: "hr-thoeng.firebaseapp.com",
     projectId: "hr-thoeng",
     storageBucket: "hr-thoeng.firebasestorage.app",
     messagingSenderId: "...",
     appId: "..."
   },
   ```

### 5) ขึ้นเว็บบน GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `hr-thoeng`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ **ยกเว้น `staff_import.json` และไฟล์ Excel**
3. **Settings > Pages** > Source: **Deploy from a branch** > Branch: `main` / `(root)` > Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/hr-thoeng/`

### 6) ติดตั้งครั้งแรก (ทำทันทีหลังเว็บขึ้น)
1. เปิดเว็บ จะพบหน้า **“สร้างบัญชีผู้ดูแลระบบ”** กรอกอีเมลของผู้ดูแลและรหัสผ่าน
2. ระบบพาไปหน้า **ตั้งค่าปีงบ/โครงการ** > ส่วน “นำเข้าข้อมูลบุคลากร” > เลือกไฟล์ **`staff_import.json`**
3. รอจนขึ้นสรุปผล (ประมาณ 1 วินาทีต่อคน) ระบบสร้างบัญชีให้ครูทุกคน รายชื่อที่มีปัญหาจะแสดงใต้สรุป
4. เพิ่มโครงการพัฒนาบุคลากรของปีงบประมาณ 2570
5. แจ้งครูให้เข้าระบบด้วยชื่อจริง + เบอร์โทร

## ความปลอดภัย
- รหัสผ่านจัดการโดย Firebase Authentication (เข้ารหัส และล็อกอัตโนมัติเมื่อเดาผิดหลายครั้ง)
- `firestore.rules` บังคับสิทธิ์ที่ฝั่งเซิร์ฟเวอร์: ครูอ่าน/แก้ได้เฉพาะข้อมูลของตนเอง (แก้ชื่อ เลขบัตร เงินเดือนไม่ได้) ผอ. เห็นทุกคน
- ค่า `apiKey` ใน config.js เปิดเผยได้ตามปกติของ Firebase ความปลอดภัยอยู่ที่ rules
- หน้าติดตั้งผู้ดูแลระบบใช้ได้ครั้งเดียว หลังติดตั้งแล้วจะไม่มีใครสร้างผู้ดูแลเพิ่มได้
- ชื่อผู้ใช้ผูกกับอีเมลของครู คนที่รู้ชื่อจริงของครูจะเห็นอีเมลบางส่วนที่หน้า “ลืมรหัสผ่าน”

## โควตาแผนฟรี (Spark)
อ่านข้อมูล 50,000 ครั้ง/วัน เขียน 20,000 ครั้ง/วัน พื้นที่ 1 GB — บุคลากร 30 คน ใช้ไม่ถึง 5% ระบบย่อรูปเหลือประมาณ 100–200 KB ต่อรูป เก็บได้หลายพันรายการ

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| “เชื่อมต่อฐานข้อมูลไม่ได้” | ตรวจค่า `FIREBASE` ใน config.js และอินเทอร์เน็ต |
| “ไม่มีสิทธิ์ทำรายการนี้” | ยังไม่ได้ Publish `firestore.rules` หรือวางไม่ครบ |
| ครูเข้าระบบไม่ได้ | ผอ. เปิดข้อมูลครู ดูสถานะบัญชี ถ้า “ยังไม่มีบัญชี” กด “สร้างบัญชีใหม่” |
| ไม่ได้รับอีเมลรีเซ็ต | ดูในโฟลเดอร์จดหมายขยะ หรือให้ ผอ. แก้อีเมลแล้วกด “สร้างบัญชีใหม่” |
| แก้ไฟล์แล้วหน้าเว็บไม่เปลี่ยน | รอ GitHub Pages 1–2 นาที แล้วกด Ctrl+F5 |

> หมายเหตุ: บัญชีที่ถูกแทนด้วย “สร้างบัญชีใหม่” หรือบุคลากรที่ถูกลบ จะยังมีชื่ออยู่ใน Authentication > Users แต่เข้าใช้ระบบไม่ได้แล้ว ลบทิ้งได้ที่หน้านั้น
